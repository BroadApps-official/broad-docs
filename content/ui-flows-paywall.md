# BroadUIFlows: paywall и Special Offer

Сначала описан общий сценарий платформы, затем приведены записи существующих
приложений. Записи показывают внешний вид и переход между двумя экранами;
сами приложения могут использовать другие имена, таймеры и состав карточек.

## Общий сценарий платформы

Для новой интеграции используйте [правила Special Offer](./special-offer.md):

- флаг `special_offer` читается из Remote Config закрываемого **основного
  paywall**; разрешает показ только точное булево `true`;
- окно показа длится 24 часа, затем экран закрывается и идут 24 часа cooldown;
  выключение флага, подтверждённая покупка или restore сбрасывают цикл;
- отдельный Adapty placement `special_offer` отдаёт **все** продукты для
  второго экрана в исходном порядке;
- в [общем RU-варианте](./ru-special-offer.md) продукт берётся из каталога
  backend по отметке `isSpecialOffer`, без подстановки обычного тарифа.

```text
Обычный paywall
        ├─ purchase / restore подтверждены → Premium / главный экран приложения
        └─ нажат крестик без покупки
                    ↓ если показ разрешён (флаг true и активное окно, не cooldown)
              Special Offer
                    ├─ покупка подтверждена → Premium / главный экран приложения
                    └─ нажат крестик → главный экран приложения
```

## Частный пример: Adapty в 5007

На записи 5007 сначала показывается обычный paywall с годовым
и недельным планами. Нажатие на тариф только меняет выбор и не запускает
покупку.

![5007: обновлённый обычный paywall](../public/guides/ui-flows/5007/paywall.png)

![5007: переключение между тарифами обычного paywall](../public/guides/ui-flows/5007/paywall.gif)

После нажатия на крестик основной paywall не закрывает весь сценарий: вместо
него появляется отдельный Limited-Time Offer со своей ценой и кнопкой
Continue. Это переход в записанном примере, а не обещание показывать оффер
при каждом закрытии в общем сценарии.

В доступном коде 5007 ключ — `sp_of`, placement — `SpecialOffer`; таймер
переоткрывает окно без общего cooldown 24 часа. Это особенности 5007.
[Соответствие его имён общим названиям](./adapty-integration-guide.md).

![5007: переход по крестику из обычного paywall в Special Offer](../public/guides/ui-flows/5007/special-offer.gif)

![5007: обновлённый экран Special Offer](../public/guides/ui-flows/5007/special-offer.png)

## Частный пример: Adapty в 5092

На записи 5092 крестик открывает второе предложение. Это пример перехода
и дизайна. В доступном коде 5092 cooldown отключён (`cooldown: 0`), а флаг
принимает несколько имён, включая `specialOffer`, `coupon` и `cupon`.
Такая реализация отличается от общего строгого флага `special_offer`
и цикла 24/24; переносить эти отличия в новую интеграцию не нужно.

![5092: обычный Adapty paywall, крестик и LIMITED-TIME OFFER](../public/guides/ui-flows/paywall-special-offer/5092-adapty.gif)

## Частный пример: RU Billing в Claude232

Этот пример записан в Claude232 с языком **Russian** и регионом **Russia**.
Обычный русский paywall закрывается, после чего появляется
специальное предложение RU Billing с рублёвой ценой.

В доступном коде Claude232 ключ называется `kupon`, используется собственное
окно показа и дополнительные условия. Запись не подтверждает общий цикл 24/24
и не служит инструкцией по выбору RU-продукта.

Для новой интеграции действуют общие статьи: флаг основного paywall и цикл
24/24 — из [Special Offer](./special-offer.md), выбор RU-продукта по
`isSpecialOffer` — из [RU Billing Special Offer](./ru-special-offer.md).

![Claude232: русский RU Billing paywall, крестик и специальное предложение](../public/guides/ui-flows/paywall-special-offer/claude232-ru-billing.gif)

> Важно: Russian отвечает за русскую локализацию экрана, а Russia — за
> региональный маршрут. Для повтора этого GIF в Simulator включите оба значения.

Отличия этих трёх примеров сверены по доступным исходникам 7 сентября 2026 года.
При работе с конкретным приложением сверяйте его текущую версию; общие правила
платформы задаются статьями выше, а не поведением записанной сборки.

## Почему здесь нет GIF 5115Copilot

Документация не должна показывать выдуманный маршрут. В доступной сборке
5115Copilot крестик обычного paywall открывает экран Privacy, а в
доступных исходниках нет перехода в Special Offer. Как только будет
доступна сборка с этим переходом, её можно добавить четвёртым подтверждённым
референсом.

## Граница UI и оплаты

```text
BroadUIFlows       рисует карточки, выбор, loader, ошибки и кнопки
BroadMonetization  загружает продукты, запускает purchase/restore и проверяет Premium
Adapty / backend   возвращают продукты и подтверждённый результат
Приложение         задаёт дизайн, тексты, placements и момент показа
```

Крестик только сообщает о закрытии обычного paywall. Для общего
`BroadUIFlows` + Adapty flow действует одна таблица решения:

```text
special_offer == true и активное окно показа → показать второй экран
идёт cooldown или любое другое значение        → не показывать второй экран
```

Для этого общего flow продукты приходят из Adapty placement `special_offer`.
Платёжный каталог backend и отметка `isSpecialOffer` используются только в
RU-варианте.

## Что проверить в общем BroadUIFlows flow

| Проверяем | Ожидаемый результат |
|---|---|
| Крестик обычного paywall | Special Offer открывается только при строгом `special_offer = true` в Remote Config основного paywall и активном окне |
| Продукты Special Offer | Приходят из Adapty placement `special_offer`; платёжный каталог backend в общем flow не вызывается |
| Успешные purchase и restore | Второе предложение не открывается |
| Повторное открытие внутри окна | Оффер появляется снова; после истечения окна начинается cooldown, затем цикл повторяется |
| Повторный tap | Вторая операция не запускается |
| Loader | Выбранный продукт сохраняется |
| Крестик Special Offer | Открывается главный экран приложения без Premium |
| Доступ к Premium | Открывается только после подтверждённого entitlement или backend-статуса |

## Что проверять в RU-варианте

| Проверяем | Ожидаемый результат |
|---|---|
| Gate показа | строгий `special_offer = true` в Remote Config основного paywall и активное окно |
| Продукт RU Billing Special Offer | каталог backend возвращает продукт с отметкой `isSpecialOffer`; Adapty и App Store не выбирают RU-продукт |
| Цикл показа | внутри окна оффер показывается, после истечения — cooldown, затем цикл повторяется |
