# Adapty: ключ и placements

Для обычной загрузки paywall нужны только две вещи:

1. публичный SDK key Adapty;
2. имя placement, например `main`, `tokens` или `special_offer`.

Отдельный verifier, собственный REST-клиент или access level для загрузки
paywall не нужны.

## Как данные доходят до экрана

```text
ключ Adapty + имя placement
  → запросить paywall
  → запросить его продукты
  → сохранить все продукты
  → передать их экрану приложения
```

Placement — это имя места показа в Adapty Dashboard. По этому имени Adapty
решает, какой paywall и какие продукты вернуть.

## Что где настраивается

| Значение | Где оно живёт | Почему |
|---|---|---|
| Публичный SDK key | В конфигурации приложения при запуске | Он относится к конкретному приложению |
| Имена placements | В одном списке внутри приложения | Экран выбирает понятное логическое имя |
| Paywall и продукты | В Adapty Dashboard | Их меняет владелец монетизации без новой сборки |
| Тексты и внешний вид | В ответе Adapty и/или UI приложения | Платформа не навязывает дизайн продукта |

Приложение хранит только те placements, которые действительно использует.

## Главное правило продуктов

Платформа передаёт экрану весь массив Adapty: ноль, один или любое количество
продуктов, в исходном порядке, включая повторяющиеся SKU. Она не оставляет
«лучшие два» и не сортирует по цене.

Если конкретному приложению нужны две карточки, разработчик делает это явно в
UI этого приложения. Общий модуль продолжает возвращать полный ответ, чтобы
другие приложения не теряли данные.

## Remote Config

Remote Config — дополнительные поля внутри ответа выбранного placement, а не
вторая система настроек. Например, для Special Offer платформа сейчас читает
только один флаг:

```json
{
  "special_offer": true
}
```

Если основной placement недоступен и существующий adapter Adapty выбрал
запасной, платформа использует paywall и продукты фактически полученного ответа.
Приложению не нужно добавлять второй кеш, REST-клиент или проверяющий сервис.

## Как проверить

1. SDK key передаётся один раз при запуске приложения.
2. Экран запрашивает логическое имя placement из общего списка.
3. В диагностике видно, какой placement запросили и какой фактически получили.
4. На экран приходит полный массив продуктов.
5. Покупка использует продукт из уже загруженного paywall.
6. Автоматическая проверка не списывает настоящие деньги.
