# Чат поддержки Usedesk

Usedesk даёт приложению **готовый экран переписки с поддержкой**. Разработчик не
рисует чат и не создаёт свою систему сообщений: он подключает SDK, передаёт
полученные данные и открывает готовый экран по нажатию пользователя.

## Что нам реально дают

Менеджер присылает одну карточку с четырьмя строками:

1. `Token`;
2. `Company ID`;
3. `Channel ID`;
4. готовый `<script ...>` для web-виджета.

![Вот какие данные присылает менеджер: Token, Company ID, Channel ID и web-script](../public/guides/readme/Usedesk/pm-data-sanitized.png)

На этом список входных данных заканчивается. Если в задаче нет дополнительных
функций, не запрашиваем другие данные и не придумываем дополнительную систему.

## Для чего нужна каждая строка

| Что прислали | Что это значит для разработчика iOS |
|---|---|
| `Token` | На карточке не подписано, для какого SDK-поля он выдан. Не угадываем: используем только тогда, когда рабочий iOS-пример явно сопоставляет его с полем SDK |
| `Company ID` | Указывает, к какой компании Usedesk подключается приложение |
| `Channel ID` | Указывает, в какой канал поддержки попадёт сообщение пользователя |
| `<script ...>` | Готовая вставка для сайта. В Swift-код её не копируют; она остаётся web-примером из той же карточки |

Реальное значение Token нельзя публиковать в документации, логах и открытых
скриншотах. На изображении оно скрыто специально.

## Что должен сделать разработчик

1. Добавить официальный SDK Usedesk с готовым интерфейсом в target приложения.
2. Записать `Company ID` и `Channel ID` в конфигурацию приложения; `Token` передать только в подтверждённое поле iOS SDK, если оно требуется.
3. Добавить в настройки строку `Онлайн-чат`.
4. По нажатию передать конфигурацию в Usedesk и открыть его готовый экран.

```text
карточка менеджера
        ↓
Company ID + Channel ID + подтверждённое поле Token
        ↓
конфигурация Usedesk в приложении
        ↓
Настройки → Онлайн-чат
        ↓
готовый экран Usedesk
```

Готовый интерфейс Usedesk устанавливается через CocoaPods в основное
iPhone-приложение. После `pod install` открывайте `.xcworkspace`, а не
`.xcodeproj`.

## Что увидит пользователь

В настройках появляется обычная строка `Онлайн-чат`. Она ничего не загружает
при запуске приложения. Чат открывается только после нажатия.

![Где пользователь нажимает «Онлайн-чат»](../public/guides/readme/Usedesk/settings-online-chat-highlighted.png)

После нажатия Usedesk показывает свой готовый экран переписки.

![Готовый экран переписки Usedesk](../public/guides/readme/Usedesk/chat-screen.png)

## Что сюда не относится

- `BroadCore`, `BroadMonetization` и `BroadUIFlows` не подключают Usedesk автоматически;
- web-script из карточки не вставляется в Swift;
- разработчик не создаёт собственный экран чата;
- дополнительные сервисы, хранилища и сценарии не добавляются без отдельного требования.

Usedesk остаётся опциональной интеграцией конкретного приложения. Если чат не
нужен, в приложении нет ни SDK, ни строки `Онлайн-чат`.

## Как проверить

- приложение собирается после установки SDK;
- строка `Онлайн-чат` видна в настройках;
- нажатие открывает готовый экран Usedesk;
- тестовое сообщение попадает в канал из полученного `Channel ID`;
- реальные Token и ID не выводятся в Console и не добавлены в публичную документацию.
