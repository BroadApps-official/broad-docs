# Словарь без жаргона

На страницах сайта сохранены точные названия из Xcode, Swift и Adapty. Здесь
они переведены на обычный русский язык. В конкретной инструкции рядом с
термином всегда важнее написанное действие.

## Проекты и подключение

| Термин | Что он означает |
|---|---|
| Swift Package | Библиотека, которую Xcode скачивает и подключает к приложению. |
| Repository / репозиторий | Отдельный проект на GitHub со своими файлами и историей изменений. |
| Module / модуль | Самостоятельная часть платформы с одной областью ответственности. |
| Product | Библиотека, которую нужно отметить в окне Xcode после добавления GitHub-адреса. |
| Target | То, куда Xcode добавит библиотеку; здесь почти всегда основное iPhone-приложение. |
| Host app | Само приложение компании, которое подключает общий код платформы. |
| Dependency | Другая библиотека, без которой выбранный модуль не может работать. |
| Package resolve | Этап, на котором Xcode находит нужные версии и скачивает библиотеки. |
| Local path dependency | Библиотека, подключённая из папки на компьютере вместо публичного GitHub-адреса. |

## Работа приложения

| Термин | Что он означает |
|---|---|
| Bootstrap | Действия при запуске: создать общие сервисы, прочитать сохранённые данные и открыть первый экран. |
| Composition root | Одно стартовое место, где приложение создаёт библиотеки и передаёт им настройки. |
| Runtime | Работа уже запущенного приложения, а не его сборка в Xcode. |
| Cache / кеш | Локальная копия данных для быстрого или офлайн-запуска. |
| Fallback | Запасной безопасный вариант, если основной источник недоступен. |
| Adapter | Небольшой переводчик между ответом внешнего сервиса и данными, понятными приложению. |
| Boundary | Правило о том, какая часть системы отвечает за конкретное действие или данные. |
| Lifecycle | Последовательность состояний экрана или операции от начала до завершения. |

## Оплата

| Термин | Что он означает |
|---|---|
| Placement | Имя нужного экрана в Adapty, например `main` или `tokens`. |
| Paywall | Экран, на котором человек выбирает подписку или покупку. |
| Product | Один вариант покупки, полученный от Adapty или StoreKit. |
| Payload | Набор данных, который вернул Adapty или сервер приложения. |
| Provider | Сервис, который вернул данные или провёл оплату: Adapty, Apple либо сервер приложения. |
| Entitlement | Подтверждение системы оплаты, что пользователю действительно доступен Premium. |
| Pending | Операция началась, но сервер ещё не подтвердил окончательный результат. |
| Restore | Повторная проверка ранее совершённых покупок Apple. |

## Проверки и выпуск

| Термин | Что он означает |
|---|---|
| Fixture / probe | Демонстрационная проверка кода без настоящей покупки и изменения данных пользователя. |
| Gate | Автоматическая проверка перед объединением или выпуском изменений. |
| Acceptance | Финальная приёмка по заранее согласованному списку результатов. |
| Vertical slice | Одна функция приложения целиком: от нажатия на экран до получения результата. |
| Cutover | Один шаг, в котором старую библиотеку отключают, а новую подключают. |
| Debug / Release | Тестовая и предназначенная для выпуска конфигурации сборки. |
| QA | Проверка приложения специалистом по качеству после проверки разработчиком. |
| ATT | Системный запрос Apple на разрешение отслеживания пользователя. |

## Как читать команды

Текст в тёмном блоке — пример команды или кода. Не вставляйте его вслепую:
сначала прочитайте действие перед блоком и замените примерные адреса или имена
на значения своего приложения.
