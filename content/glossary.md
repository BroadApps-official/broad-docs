# Словарь без жаргона

Здесь собраны слова из Xcode, Swift, платформы, настроек оплаты и процесса разработки. В каждой строке есть смысл, конкретный пример и ссылка на следующий шаг. Точное английское название сохранено, чтобы его можно было найти в интерфейсе или сообщении об ошибке.

Для поиска слова на странице нажмите **⌘F**. Для поиска по всем статьям используйте поиск сайта. Сначала выберите раздел по ситуации: подключение, код, данные, экраны, оплата, RU Billing, поддержка или выпуск.

На скриншоте слева находятся скачанные **packages**, справа — **products**, добавленные в выбранный **target**.

## Как читать команды и примеры кода

Над каждым блоком указано, где его выполнять и что он должен дать. **Swift-код вставляется в исходники; bash-команды выполняются в Terminal.** Заголовок блока не означает, что любой фрагмент можно вставить в пустой файл и получить целую программу.

```bash
git status --short
```

Здесь `git` — программа, `status` — действие, `--short` — параметр короткого вывода. Команда только показывает состояние файлов. Строку приглашения Terminal, если она видна на чужом скриншоте, копировать не нужно.

| Запись | Как её понимать |
|---|---|
| `cd folder` | Перейти в папку folder; дальнейшие команды работают из неё |
| `\` в конце строки bash | Одна команда продолжается на следующей строке; после символа не должно быть лишнего пробела |
| `NAME=value command` | Переменная действует для этого запуска команды |
| `--option value` | Параметр команды и его значение |
| `import BroadCore` | Swift-файл использует API модуля; библиотека должна быть подключена к target |
| `// пояснение` | Комментарий в Swift, а не выполняемое действие |
| `.loaded(items)` | Конкретный вариант состояния LoadableState с данными |
| Имена `AppFeature`, `BroadStart`, `com.example.…` | Имена учебного примера; для своего приложения выбирайте согласованные значения |

Если инструкция не объясняет, какой файл менять, где запускать команду или какой результат ждать, сначала найдите полный пример по ссылке рядом. [Первое подключение](./getting-started.md) и [исходники BroadStart](https://github.com/BroadApps-official/broad-docs/tree/main/examples/first-app) показывают команды вместе с контекстом.
