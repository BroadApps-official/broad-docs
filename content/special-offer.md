# Спешл оффер (от Adapty)

Это второй экран покупки из Adapty. Он открывается после того, как пользователь
закрыл обычный paywall без подтверждённой покупки или restore. В Adapty для
него используется отдельный placement `special_offer`.

Эта страница не описывает RU Billing. Российский продукт, СБП/карта и точное
сопоставление с Adapty описаны на странице
[«RU Billing: спешл оффер»](./ru-special-offer.md).

## Когда он показывается

```text
обычный paywall
  ├─ purchase / restore подтвердили Premium → главный экран приложения
  └─ пользователь нажал крестик
       → прочитать special_offer из текущего Adapty Remote Config
       ├─ любое значение, кроме точного boolean true → главный экран приложения
       └─ true → всегда запросить placement special_offer
                  → показать второй экран со всеми продуктами Adapty
```

Решение всегда сводится к одному значению текущего Remote Config:

```text
special_offer == true → всегда показать Special Offer
любое другое значение → не показывать Special Offer
```

Это единственный gate. Приложение не добавляет к нему собственные условия.
Если Adapty вернул configured fallback, приложение читает флаг из
фактически загруженного payload и не добавляет отдельный fallback-gate.

## Без временных ограничений

В этом контракте нет таймера, cooldown, даты окончания или лимита повторных
показов. При `special_offer = true` второй экран открывается после каждого
подходящего закрытия обычного paywall.

## Какие продукты показываются

Платформа передаёт **все** варианты фактически полученного ответа Adapty и
сохраняет их порядок. Она не объединяет их и не оставляет только две карточки.

Ограничение количества карточек возможно только как явное решение конкретного
приложения.

## Если Adapty вернул запасной экран

Платформа использует экран, варианты покупки и Remote Config из того ответа,
который был реально получен. Она не смешивает запрошенный и запасной ответы и
не загружает их заново перед показом.

![Шаг 1 — обычный экран подписки](../public/guides/readme/References/special-offer-step-1-paywall.png)

![Шаг 2 — спешл оффер Adapty после закрытия первого экрана](../public/guides/readme/References/special-offer-step-2-offer.png)

Кадры показывают только порядок экранов. Фон, тексты, число карточек, скидка и
legal-ссылки принадлежат приложению и ответу Adapty.

## Как проверить

1. Обычный paywall всегда появляется первым.
2. Подтверждённый Premium сразу ведёт на главный экран приложения.
3. Без точного `special_offer = true` второй экран не появляется.
4. При `special_offer = true` второй экран показывается всегда.
5. На втором экране видны все продукты в порядке Adapty.
6. Повторное подходящее закрытие снова открывает экран без паузы.
7. В реализации нет таймера, cooldown, даты окончания и лимита показов.
8. Безопасная демонстрация не совершает настоящих финансовых операций.
