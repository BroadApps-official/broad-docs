# Спешл оффер (от Adapty)

Это спешл оффер, который приходит именно из Adapty. Он показывается вторым
экраном покупки, если пользователь закрыл обычный экран подписки и ничего не
купил. В Adapty для него используется отдельное имя места показа
`special_offer`.

Эта страница не описывает спешл оффер для RU Billing. Российский coupon-flow,
СБП/карта и отдельные правила таймеров описаны на странице
[«RU Billing: спешл оффер»](./ru-special-offer.md).

## Когда он показывается

```text
обычный экран подписки
  ├─ покупка или restore подтвердили Premium → открыть основное приложение
  └─ пользователь нажал крестик
       → запросить в Adapty экран special_offer
       → получить экран и все варианты покупки
       → кампания активна, если special_offer не равен false
       → показать второе предложение
```

Если первая покупка подтвердила Premium, второй экран не показывается. Кампания
активна по умолчанию: её выключает только явный `special_offer = false` в ответе
провайдера. Экран должен быть собственным непустым экраном placement — запасной
(подменённый) экран под спешл оффер не идёт.

## Какие продукты показываются

Платформа передаёт **все** варианты фактически полученного ответа Adapty и
сохраняет их порядок. Она не объединяет их и не оставляет только две карточки.

Ограничение количества карточек возможно только как явное решение конкретного
приложения.

## Таймер: два режима

- **Без расписания (untimed).** Таймер — визуальная анимация
  `24:00:00 → 00:00:00 → снова 24:00:00`. Он не читает время, не сохраняется и не
  блокирует кнопку. Оффер показывается, пока грузится разрешённый собственный
  экран.
- **С расписанием (timed).** Платформа включает кадэнс «сутки через сутки»:
  оффер идёт окно (по умолчанию 24 часа) и показывается на каждом закрытии
  первого экрана в течение окна, затем сутки тишины, затем следующее закрытие
  открывает новое окно. Отсчёт ведётся по **доверенному серверному времени**
  (не по часам устройства) и переживает перезапуск; без доверенного времени оффер
  не показывается. Покупка сбрасывает окно.

## Если Adapty вернул запасной экран

Платформа использует экран, варианты покупки и переключатель из того ответа,
который был реально получен. Она не смешивает запрошенный и запасной ответы и
не загружает их заново перед показом.

![Шаг 1 — обычный экран подписки](../public/guides/readme/References/special-offer-step-1-paywall.png)

![Шаг 2 — спешл оффер Adapty после закрытия первого экрана](../public/guides/readme/References/special-offer-step-2-offer.png)

Кадры показывают только порядок экранов. Фон, тексты, число карточек, скидка и
legal-ссылки принадлежат приложению и ответу Adapty.

## Как проверить

1. Обычный экран подписки всегда появляется первым.
2. Подтверждённый Premium сразу ведёт в основное приложение.
3. Явный `special_offer = false` выключает второй экран; отсутствие флага — нет.
4. На втором экране видны все продукты в порядке Adapty.
5. Без расписания таймер зациклен; с расписанием окно живёт по серверному
   времени и переживает перезапуск.
6. Безопасная демонстрация не совершает настоящих финансовых операций.
