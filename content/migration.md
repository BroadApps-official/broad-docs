# Почему платформу разделили

Раньше общий код жил в одном большом репозитории BroadCore. Сейчас он разделён
на четыре публичных модуля. Эта страница объясняет историю самой платформы.

Если нужно перевести работающее приложение со старого BroadCore, используйте
[отдельную инструкцию миграции приложения](./legacy-app-migration.md).

## Что было сделано

| Раньше | Сейчас |
|---|---|
| Один большой private BroadCore | Четыре публичных модуля с отдельными версиями |
| Приложение получало лишние части | Приложение выбирает только нужный модуль |
| Одна общая история изменений | У каждого модуля свой changelog и release |
| Совместимость приходилось угадывать | `broad-platform-integration` хранит проверенные версии |
| Общая инструкция терялась в README | Общие объяснения находятся на этом сайте |

## В каком порядке выносили код

```text
Общие правила → документация → Extensions → Core
              → Monetization → UIFlows → переключение примера
```

Порядок шёл от независимого к зависимому. Нельзя выпустить UIFlows, который
ссылается на ещё не опубликованную версию Monetization.

## Что проверяли после каждого модуля

1. Репозиторий открывается и скачивается без логина.
2. `Package.swift` содержит только необходимые зависимости.
3. Package и демонстрационное iPhone-приложение собираются.
4. README, DocC, ссылки, картинки и история изменений актуальны.
5. В модуле нет ключей и данных конкретного приложения.
6. Интеграционный пример продолжает собираться.

Тестовые сценарии платформы выполняются безопасными исполняемыми примерами без
настоящих финансовых операций. По решению владельца XCTest и Swift Testing в
репозитории модулей не используются.

## Что осталось после разделения

`broad-platform-integration` хранит точные версии, `BroadAppTemplate` и общую
проверку. Он не является библиотекой приложения. После публикации четырёх
модулей пример переключили с локальных копий на публичные версии и только потом
отметили набор как проверенный.

Исходные Swift-файлы переносились вместе с относящейся к ним историей Git. Это
позволяет увидеть происхождение кода и причины старых решений.
