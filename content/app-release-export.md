# Подготовка приложения к App Store

Эта инструкция для разработчика приложения, в котором подключены пакеты BroadApps. Перед выпуском команда создаёт отдельную копию проекта: исходники используемых модулей BroadApps находятся в ней локально, а сторонние зависимости остаются в Swift Package Manager. Основная ветка приложения не меняется.

## Четыре шага

1. Закончите изменения приложения и сохраните их в коммит. Убедитесь, что в Xcode указана нужная версия приложения.
2. Из корня репозитория приложения выполните одну команду:

   ```bash
   bash Scripts/prepare_release.sh
   ```

3. Дождитесь сообщения `Готово. Релизный проект: ReleaseExport/<версия>`. При ошибке следуйте подсказке команды; не исправляйте ссылки на пакеты вручную.
4. Используйте папку `ReleaseExport/<версия>` для финальной сборки. В настроенном CI, например у 5112, этот же экспорт создаётся автоматически перед сборкой `.ipa`.

Команда сама определяет версию из Xcode, берёт точные версии пакетов, переносит только нужные исходники BroadApps, меняет прямые и вложенные ссылки на локальные пути, проверяет проект и собирает его без подписи. Первое выполнение может занять время, пока загружаются сторонние зависимости.

## Что должно получиться

- В `ReleaseExport/<версия>` лежит собираемый проект без `.git` и без удалённых ссылок на пакеты BroadApps. Ссылки на сторонние SDK допустимы.
- Сообщение `Готово` появляется только после успешной проверки. Если команда остановилась с ошибкой, релизный проект не готов.
- Внутренний отчёт о версиях и коммитах пакетов находится отдельно, в `ReleaseRecords/<версия>.json`. Он не включается в проект и проверяется на отсутствие в финальном `.ipa`.

Повторный выпуск той же версии не перезаписывает готовую папку молча. Если нужно исправить приложение, зафиксируйте новый коммит, удалите прежний локальный экспорт после проверки и запустите команду снова.

## Если команда не запустилась

| Сообщение | Действие |
|---|---|
| «Сначала сохраните изменения приложения в коммит» | Создайте коммит и повторите команду. |
| «Укажите одинаковый MARKETING_VERSION» | Настройте одну версию приложения для всех конфигураций app target в Xcode. |
| «Нет точной версии» | Зафиксируйте версию пакета в Xcode или обратитесь к владельцу платформы. |
| «Не удалось получить пакет» | Проверьте доступ к сети и повторите запуск. Если тег отсутствует, сообщите владельцу платформы. |
| «Сборка завершилась с ошибкой» | Передайте владельцу приложения текст ошибки сборки. Не отправляйте полученную папку на релиз. |

Если в репозитории приложения пока нет `Scripts/prepare_release.sh`, попросите владельца платформы подключить к нему выпускной инструмент. Не копируйте исходники модулей вручную.
