# BroadStart

Учебный iPhone-каталог для раздела [«Старт»](https://broadapps-ios-docs.nkhsnv.chatgpt.site/docs/getting-started).
Пять Swift-файлов, два экрана, локальные данные и воспроизводимые состояния.
Core 1.2.0 предоставляет LoadableState и AppError; Extensions 1.0.1 — HEX-цвет.

## Открыть

Откройте `BroadStart.xcodeproj`, дождитесь загрузки пакетов, выберите схему
BroadStart и iPhone Simulator, нажмите Run. XcodeGen не нужен для готового проекта.
Проверено на Xcode 26.3, iOS Simulator 26.3; минимум приложения iOS 17, Swift 5,
iPhone only, Team None. Настройки повторно генерируются из project.yml через
XcodeGen 2.45.4, если вы пользуетесь этим инструментом.

```bash
open BroadStart.xcodeproj
```

Все зависимости публичны и используют точные версии. Package.resolved хранится
в `BroadStart.xcodeproj/project.xcworkspace/xcshareddata/swiftpm/`.
Ни локальные копии платформы, ни ключи сервисов не нужны.

## Пройти

1. Дождитесь трёх материалов, откройте любой, вернитесь назад.
2. Обновите список: содержимое остаётся, кнопка временно недоступна.
3. Выберите «Пусто»: виден пустой результат с пояснением.
4. Выберите «Ошибка»: показаны сообщение и явный повтор.
5. Нажмите «Повторить со списком»: три материала снова доступны.
6. Из списка выберите «Ошибка»: материалы остаются, показано сообщение об ошибке обновления.
7. Перезапустите приложение: учебный режим не сохраняется, снова загружается список.

Переключатель имитирует ответы. DemoLessonRepository не выполняет сетевых
запросов. Ошибка offline и задержка 0,8 секунды подготовлены для демонстрации;
это не проверка настоящей сети. Оплаты, аккаунта, поддержки и ATT в примере нет.

## Разобрать код

- `Sources/Lesson.swift`: данные, протокол источника, операция загрузки.
- `Sources/DemoLessonRepository.swift`: локальная реализация источника.
- `Sources/LessonListModel.swift`: состояния и защита повторного нажатия.
- `Sources/LessonListView.swift`: список и материал в SwiftUI.
- `Sources/BroadStartApp.swift`: однократное создание зависимостей и цвет.
