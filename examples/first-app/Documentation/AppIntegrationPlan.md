# BroadStart — учебное приложение для раздела «Старт»

## Назначение и границы

Пользователь запросил работающий пример создания приложения со скриншотами.
Это самостоятельный учебный каталог из трёх материалов; дизайн и тексты созданы
для этого примера. Он не копирует приложение компании и не подключается к серверу.
Ошибки и задержка специально воспроизводятся локальным DemoLessonRepository.
На экране явно написано «Учебный пример · локальные данные».

## Подключение

- iPhone, iOS 17+, Swift language mode 5, Team None.
- BroadCore 2.0.0: LoadableState и AppError.
- BroadExtensions 1.0.1: Color(broadHex:).
- Источник: Compatibility/current.yml из broad-platform-integration, set 1.4.0.
- Монетизация, аккаунт, сервер, ATT и поддержка: N/A для этого учебного каталога.
- Оба product явно подключаются к BroadStart, поскольку оба импортируются его кодом.

## Пользовательские сценарии

| Сценарий | Источник и реализация | Приёмка |
|---|---|---|
| Запуск → список | Локальный DemoLessonRepository → LessonListModel → LessonListView | Три материала после загрузки |
| Список → материал → назад | SwiftUI NavigationStack; содержимое из Lesson | Заголовок и полный текст выбранного материала |
| Обновить | LoadableState.loading(previousValue:) | Список остаётся на месте, кнопка заблокирована |
| Пустой результат | Режим «Пусто» в учебном управлении | Понятное пояснение, возможность выбрать список |
| Ошибка без данных | Режим «Ошибка» после пустого результата | Ошибка и явный повтор |
| Ошибка обновления | Режим «Ошибка» после списка | Старые учебные материалы остаются, видна ошибка |
| Повтор | Явная кнопка «Повторить со списком» | Новый запрос, затем три материала |

## Структура

Lesson — модель данных. LessonRepository — граница источника данных.
LoadLessonsUseCase — получение списка. LessonListModel — состояния и действия.
LessonListView — интерфейс. BroadStartApp создаёт и связывает объекты один раз.
Никакого app-specific кода внутри модулей платформы.
